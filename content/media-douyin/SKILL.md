# Media Douyin

本技能只处理抖音平台化工作。素材发现、事实核验、账号配置和跨平台调度由 `media-ops` 总控负责。

## Adapt content

- 交付标题、前三秒钩子、分镜、口播、字幕重点、素材清单和来源说明。
- 结构优先采用“钩子 → 背景 → 关键证据 → 解释/建议 → 收束行动”。前三秒具体、可信，不制造虚假紧迫感。
- 数据、专有名词和引用设计为屏幕文字；每个镜头注明画面、口播、字幕和来源。
- 结尾引导一个具体动作或问题，不使用空泛求赞；系列内容要说明下一集价值。

## Media and review

配音、音乐、人物肖像和第三方视频片段必须有可用权限。发布前检查时长、画面、字幕、来源、账号身份和发布按钮；发布按钮只点击一次，并核对成功提示或作品时间线。
