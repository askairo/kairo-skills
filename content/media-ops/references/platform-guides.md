# 平台化改编指南

平台规则会变化。若精确长度、格式、链接、音乐、商业披露或自动化限制影响交付，先查阅对应平台的当前官方说明。

## Twitter/X

目标是快速传达可核验事实并开启讨论。

- 首条先给事实变化或清晰观点，避免空泛悬念。
- 单帖只承载一个核心信息；信息链较长时使用 thread，并让每帖能独立理解。
- 区分“来源称”“我的判断”和“尚待观察”。
- 放置原始来源或最关键证据链接；引用原话时保持最短必要长度。
- 结尾使用具体问题、判断或延伸阅读入口，不使用无关标签堆叠。

交付：成稿、建议的单帖/thread 形式、来源链接、可选配图说明。

## 小红书

目标是提供易理解、值得收藏的中文解释。

- 标题表达明确收益或认知差异，但不得超出证据。
- 开头快速交代“发生了什么、为什么与你有关”。
- 正文采用短段落和清晰小标题，补充背景、个人化解释与可执行结论。
- 图文卡片一页一个信息单元，封面承诺必须由正文兑现。
- 在正文或末尾清楚标注来源与资料日期；商业关系或利益关联必须披露。

交付：3 个标题候选、正文、封面文案、卡片页纲、来源区和标签建议。

## 抖音

目标是在短时间内建立问题、证据和观看回报。

- 前三秒使用具体变化、反常识或受众痛点作为钩子，不制造虚假紧迫感。
- 口播按“钩子 → 背景 → 关键证据 → 解释/建议 → 收束”推进。
- 将数据、专有名词和引用设计为屏幕文字；需要展示来源时给出可读的出处画面。
- 为每个镜头注明画面、口播、字幕和素材来源；缺失素材使用占位符，不虚构画面。
- 配音、音乐、人物肖像和第三方视频片段必须有可用权限。

交付：标题、前三秒钩子、分镜表、完整口播稿、字幕重点、素材清单和来源说明。

## 跨平台一致性检查

- 核心事实、数字、日期和来源保持一致。
- 允许角度、节奏和结构不同，不允许为了平台效果改变事实含义。
- 每个平台版本都应有独立价值，不能只替换标题和换行。
- 对同一推断使用一致的置信度表达。
- 任何平台版本出现新的事实主张，都必须回到证据卡补充来源。
