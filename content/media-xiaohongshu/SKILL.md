# Media Xiaohongshu

本技能处理小红书平台策略、素材发现建议、平台筛选、改编和发布。`media-ops` 先传入账号目标、内容主体、受众、来源边界和发布策略；本技能据此生成小红书专属发现策略，再接收核验后的候选完成平台筛选和发布。

## Build the discovery brief

- 先明确账号的搜索意图、内容主体和读者收益，再决定发现关键词、来源类型和候选形式；不把其他平台的热门帖子直接搬运为选题。
- 优先发现可被整理为清单、步骤、对比、避坑或经验框架的原始材料；用搜索相关性、收藏价值、信息密度和账号承接判断候选。
- 为每个候选记录来源、核心事实、读者问题、可收藏结构、图片/截图权限和搜索词边界；热度只作为新鲜度和需求强度的辅助信号。

## Adapt content

- 交付 3 个标题候选：明确主题、读者收益或认知差异，不用虚假夸张词。
- 标题必须在发布前校验为不超过 20 个字符（包括标点和 emoji）；编辑器出现 `超过 20`、`X / 20` 或类似校验提示时，先压缩标题再进入发布动作。
- 开头快速说明“发生了什么、为什么与你有关”；正文用短段落和小标题。
- 优先提供可收藏的清单、步骤、对比或避坑建议；每张卡片只承载一个信息单元。
- 封面承诺必须由正文兑现；来源、日期、事实与个人判断清晰分开。
- 标签围绕真实主题，不堆叠无关热门词；商业关系、素材来源和必要披露必须明确。

### Visual consistency

- 当账号已有历史笔记视觉规范时，先检查最近一条已发布笔记，再沿用其色彩、版式、信息密度和视觉焦点；不要仅凭通用“财经风”重新设计。
- 对已配置为克制商业/产业观察风格的账号，优先采用其本机配置指定的底色、文字色和点缀色；使用信息卡排版和充足留白，避免写实插画、复杂渐变、无关装饰和堆叠素材。
- 封面只承诺正文解释的一个问题，主题短句放在左上或中上区域，辅助信息分层缩小；每张卡片只承载一个事实或判断。

## Media and review

配图、截图、信息卡和视频必须真实、清晰、具备使用权限；不为凑九宫格重复或拼接无关图片。发布前检查标题、封面、正文、来源区、标签、账号身份和发布按钮；发布按钮只点击一次并等待明确结果。

- 发布前重新读取编辑器中的最终标题、正文和媒体状态，确认标题长度校验已通过。
- 点击发布后只接受明确的成功提示、已发布状态、帖子 URL 或账号时间线新内容；如果页面仍停留在编辑器、出现校验错误或状态不明确，不得重试，记录为“发布未确认”，并在运行记录中保留具体页面信号。
- 发布未确认时，不得把候选写入已发布清单，也不得推进来源游标；后续运行应按去重和“不重试未确认候选”规则处理。
