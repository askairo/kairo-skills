# 小红书图文文本框架

## 适用目标

这套规范用于“人物观点、商业思维、企业观察”类图文。目标不是复述来源，而是把一个可核验的公开表达，整理成读者愿意点开、读完、收藏并参与讨论的单一问题答案。

小红书的选题与文本同时服务于搜索和推荐：平台公开规则显示，热点排序会综合搜索、传播、互动和点击；平台审核也要求标题、封面与正文一致，禁止夸张标题、蹭热度和对其他相似平台的过度探讨。因此文本要具体、可检索、有信息增量，但不能用平台名或夸张承诺代替内容价值。

## 一篇笔记只讲一个问题

发布前先写一句“这篇笔记回答什么问题”：

```text
读者问题：________？
核心结论：________。
读者看完能带走：一个判断 / 一张清单 / 一个方法 / 一个反思角度。
```

如果同一素材同时包含多个问题，拆成系列，不在一篇笔记中堆叠背景、人物经历、公司分析和投资结论。

## 标准文本结构

### 1. 标题：关键词 + 张力 + 明确收益

- 提供 3 个候选，最终只选 1 个；不超过 20 个字符。
- 标题优先出现核心人物或主题关键词，例如“段永平”“长期主义”“企业经营”。
- 用具体问题、反差、判断或结果制造点击理由，不用“震撼”“绝了”“必看”“全网都在”等空泛词。
- 标题必须准确承诺正文会回答的问题；不能用热点人物或平台热度吸引点击后讲别的内容。

可用结构：

```text
段永平：真正难的是不做什么
段永平的一个经营提醒
为什么长期主义很难坚持？
```

### 2. 开头：三句内让读者进入问题

```text
第 1 句：指出一个具体困惑、反差或正在发生的现象。
第 2 句：给出人物公开表达中的关键事实或判断。
第 3 句：告诉读者本文将解释什么，以及能带走什么。
```

禁止用“今天给大家分享”“相信很多人都知道”“在某平台上，某账号发布了……”作为开头。

### 3. 正文：短文四步

```text
一、上下文
用 1—2 句说明网友说了什么、讨论在谈什么；只保留理解原话所必需的背景。

二、人物原话/原意
保留最短必要引语，或准确转述段永平自己说了什么；明确区分原话和编辑转述。

三、理念解释
用 1—2 段把这句话放回段永平已经核验的经营、投资或生活理念中，解释“为什么这样说”，不替他补写没有说过的结论。外部资料只用来补充话题背景。

四、一句引导
用一句可讨论、可带走的问题或观察角度收束，不堆清单，不写成荐股或收益承诺。
```

每段只完成一个任务。默认正文控制在 180—320 字；素材很短时宁可更短，不为了“完整”堆背景、资料和多条建议。事实、人物原意和编辑解读必须分开，不用“人物认为”替代证据，也不把编辑推断伪装成人物原话。

### 4. 结尾：总结 + 一个具体问题

先用一句话收束核心判断，再提出一个能回答的问题，例如“你在工作或经营中遇到过类似取舍吗？”不要使用“点赞收藏关注我”“评论区扣 1”等机械求互动话术。

### 4.1 收藏与分享价值门禁

每篇笔记至少提供一个读者可以带走、复用或转给特定对象的具体单元，四选一：

- 一个判断顺序：先看什么，再看什么，最后避免什么；
- 一张短清单：适用条件、关键问题和常见误区；
- 一个对比框架：两种选择分别适用于什么情况；
- 一句可复述的原则：不能只写漂亮金句，必须有上下文和使用场景。

“值得收藏”“转给需要的人”不能代替实际价值。结尾只保留一个具体问题，并让问题自然承接上述判断或清单；不同时堆叠收藏、转发、点赞和关注请求。发布前检查：读者是否能说明“我为什么要保存这篇”，以及是否能指出“我会转给哪类人”。

### 5. 标签：主题词、问题词、场景词

通常使用 4—6 个标签，优先覆盖：

- 人物词：`#段永平`
- 主题词：`#长期主义`、`#企业经营`
- 问题词：`#商业思维`、`#管理思考`
- 场景词：根据正文选择 `#投资思考`、`#创业思考` 等

标签必须与正文真实相关；不使用来源平台名、无关热词或为了扩大曝光而堆叠的泛标签。

## 账号主题专用约束：大道无形我有型

- 公开主语统一使用“段永平”，不要使用“某平台作者”“某账号”“某平台用户”等表述。
- 标题、正文、结尾、标签和卡片文字均不得提及“雪球”或其他平台名称；来源平台只保留在内部证据卡、版权记录和发布核验记录中。
- 不把段永平的公开表达写成账号自身经历、确定事实或投资建议；使用“公开表达中”“我的理解”“这可以启发我们观察……”等边界词。
- 每篇只提炼一个观点，不罗列多条语录，不用“段永平说了很多……”作为主线。
- 人物热度不是选题理由；选题必须能回答一个具体经营、管理、长期主义或企业判断问题。

## 发布前文字门禁

逐项确认：

- 标题不超过 20 个字符，且标题、封面、正文回答同一个问题。
- 开头 3 句内出现具体问题、人物的事实/判断和读者收益。
- 正文按“事实/原意 → 判断 → 解释 → 可带走信息”递进，没有段落跳跃。
- 删除平台名、账号名、来源叙述和与主题无关的背景；内部来源记录不等于公开文案。
- 所有引语、数字、时间和人物归因可回溯；推断使用边界词。
- 没有绝对化、夸张、收益保证、荐股或机械求赞求收藏表达。
- 结尾只有一个具体讨论问题，标签 4—6 个且与正文一致。

## 复盘指标

不要只看阅读量。按“曝光 → 点击 → 读完/停留 → 点赞 → 收藏 → 评论 → 关注”拆解：

- 曝光低：检查主题词、标题关键词、账号垂直度和发布时间。
- 点击低：检查封面与标题是否给出具体问题和清晰收益。
- 阅读/收藏低：检查开头是否过长、正文是否提供可复用结构。
- 评论低：检查结尾是否提出了具体取舍问题，而不是泛泛求互动。

每次只调整一个变量，连续观察同一类型笔记，不用单篇爆文推导稳定规律。
