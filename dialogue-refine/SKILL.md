# Dialogue Refine

将发散的 AI 对话整理为结构清晰、主题集中的 Hexo 文章。

## 适用场景

- 对话很多，但用户希望整理成一篇可发布文章。
- 需要从讨论、问答、脑暴记录中提炼主题和结论。
- 需要统一标题层级、段落结构和 Markdown 风格。

## 处理流程

1. 读取原始对话。
   - 支持文件、剪贴板或直接输入。
   - 保留必要上下文，避免误删关键结论。
2. 提炼主题。
   - 找出核心议题和主线结论。
   - 去掉跑题、重复和无效寒暄。
3. 重组结构。
   - 将问答式内容改写为叙述式文章。
   - 补足段落之间的过渡和层次。
4. 规范格式。
   - 统一 Markdown 标题层级。
   - 规范列表、引用和代码块。
5. 输出文章。
   - 生成可直接用于 Hexo 的 Markdown 文档。
   - 必要时补充标题、摘要和标签建议。

## 使用原则

- 不要机械拼接原文，优先重写成可读文章。
- 不要丢失关键结论、步骤和上下文关系。
- 用户要求保留原话时，只保留必要引用。
- 主题不清晰时，先帮助用户收敛主线。
