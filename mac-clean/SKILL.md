# Mac Clean

用于清理 macOS 磁盘空间或整理长期积累的文件。默认优先低风险操作，不主动碰系统关键目录和个人文件。

## 目标

- 先用低风险方式回收空间。
- 展示清理前后容量变化。
- 高风险操作必须先确认。

## 安全原则

- 默认不碰 `Desktop`、`Documents`、`Pictures`、`Videos`、`Downloads`。
- 默认不碰 `C:\Program Files`、`C:\Program Files (x86)`、`C:\ProgramData` 这类安装目录。
- 不要手动删除系统级关键目录。
- 只优先清理已知缓存、临时文件和可重复生成的内容。

## 默认流程

1. 先看当前磁盘空间。
2. 清理常见缓存：
   - 用户临时目录
   - 系统临时目录
   - 浏览器/应用缓存
   - 构建工具缓存
3. 如果适合，再做组件级清理。
4. 最后汇总清理结果、回收空间和未处理项。

## 模式

- `safe`：默认模式，只做低风险清理。
- `aggressive`：只有用户明确要求时才进入，包含更激进但仍可控的清理动作。

## 输出要求

- 清理前可用空间
- 已清理路径
- 失败或被占用的路径
- 清理后可用空间
- 下一步可选高风险动作
