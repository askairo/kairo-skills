# Merge To

用于把一个已完成的功能分支合并到集成分支 `dev` 或 `sit`，并推送更新后的目标分支。

## 规则

- 只处理 `dev` 和 `sit`。
- 如果用户没指定目标，默认按 `dev` 再 `sit` 的顺序处理。
- 如果当前分支本身就是 `dev`、`sit`、`master` 或 `release`，直接拒绝，避免把集成分支当开发分支。

## 流程

1. 确认当前仓库和源分支。
2. 检查目标分支是否存在。
3. 合并前先确认工作区状态。
4. 执行合并，处理冲突。
5. 推送目标分支。
6. 再切回原分支。

## 注意

- 默认不自动猜测用户想合到哪个环境。
- 如果仓库有自己的分支规则，以仓库规则为准。
